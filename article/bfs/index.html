Breadth-First Search (BFS)

Breadth-First Search (BFS) — kenglik bo'yicha qidiruv algoritmi bo'lib, grafni daraja-darajalab (level-order) aylanib chiqadi: avval boshlang'ich tugunga, so'ng unga bevosita qo'shni bo'lgan barcha tugunlarga, keyin ularning qo'shnilariga tashrif buyuradi. BFS navbat (queue) tuzilmasiga asoslangan va og'irliksiz (unweighted) graflarda ikki tugun orasidagi eng qisqa yo'lni topishga kafolat beradi.

Illustration

BFS'ning asosiy g'oyasi

  • Navbat (Queue): "Tashrif buyurilishi kerak" tugunlar ro'yxati navbat sifatida saqlanadi — FIFO (birinchi kirgan, birinchi chiqadi) tartibida ishlaydi.
  • G'oya: Navbatdan tugun olinadi, "ko'rilgan" deb belgilanadi, so'ng uning barcha ko'rilmagan qo'shnilari navbatga qo'shiladi. Bu jarayon navbat bo'shaguncha davom etadi.
  • Level-order: Natijada tugunlar aynan ildizdan masofasi (daraja) bo'yicha ketma-ket tashrif buyuriladi.

BFS qadam-baqadam qanday ishlaydi?

Quyidagi grafda (a — boshlang'ich tugun) BFS qanday yurishini ko'ramiz. Har bir qadamda navbatdan bir tugun chiqariladi va uning ko'rilmagan qo'shnilari navbatga qo'shiladi:

Graf:     a - b - c
          |       |
          d       f - g
          |           |
          e           h - i

1-qadam: navbat = [a]           -> a ni chiqar, qo'shnilari (b, d) qo'shiladi
2-qadam: navbat = [b, d]        -> b ni chiqar, qo'shnisi (c) qo'shiladi
3-qadam: navbat = [d, c]        -> d ni chiqar, qo'shnisi (e) qo'shiladi
4-qadam: navbat = [c, e]        -> c ni chiqar, qo'shnisi (f) qo'shiladi
...                              -> navbat bo'shaguncha davom etadi

BFS'ning psevdokodi

bfs(v1, v2):
    navbat yarating, boshida faqat v1 ni saqlang
    v1 ni "ko'rilgan" deb belgilang
    navbat bo'sh emas va v2 topilmagan ekan:
        navbatdan tugun v ni chiqarib oling
        v ning barcha ko'rilmagan qo'shnilari n uchun:
            n ni navbatga qo'shing
            n ni "ko'rilgan" deb belgilang
            n ning "avvalgi" tuguni sifatida v ni belgilang

BFS'ni JavaScriptda amalga oshirish

class Graph {
    constructor() {
        this.adjacencyList = {};
    }
    addVertex(v) {
        if (!this.adjacencyList[v]) this.adjacencyList[v] = [];
    }
    addEdge(v1, v2) {
        this.adjacencyList[v1].push(v2);
        this.adjacencyList[v2].push(v1);
    }

    bfs(start) {
        const queue = [start];
        const visited = { [start]: true };
        const result = [];

        while (queue.length) {
            const vertex = queue.shift();
            result.push(vertex);

            for (const neighbor of this.adjacencyList[vertex]) {
                if (!visited[neighbor]) {
                    visited[neighbor] = true;
                    queue.push(neighbor);
                }
            }
        }
        return result;
    }
}

Eng qisqa yo'lni topuvchi BFS

BFS, konseptual jihatdan, bir vaqtning o'zida ko'plab mumkin bo'lgan yo'llarni o'rganadi, shuning uchun topilgan yo'lni to'g'ridan-to'g'ri saqlash oson emas. Buning o'rniga, har bir tugun uchun "qaysi tugundan kelib ko'rilgan" (previous) ma'lumoti saqlanadi — qidiruv yakunlangach, maqsad tugundan boshlanib shu havolalar bo'yicha orqaga yurib, to'liq eng qisqa yo'l qayta tiklanadi.

BFS operatsiyasi uchun murakkablik tahlili

Vaqt murakkabligi

Xotira murakkabligi

O(V + E)

O(V)

N tugunli, M qirrali grafda (adjacency list bilan) BFS O(V + E) vaqt talab qiladi — har bir qirra bir marta, har bir tugun esa eng ko'pi bilan bir marta ko'riladi. Navbat va "ko'rilgan" belgilar uchun O(V) qo'shimcha xotira kerak bo'ladi.

BFS va DFS taqqoslash

  • Optimallik: BFS har doim eng qisqa yo'lni (eng kam qirra bilan) topadi — og'irliksiz graflarda. DFS esa yo'lni topishga kafolat beradi, lekin u eng qisqa bo'lishi shart emas.
  • Xotira: DFS odatda kamroq xotira talab qiladi (stack chuqurligi), BFS esa navbatda bir vaqtning o'zida ko'proq tugun saqlashi mumkin.
  • Qo'llanilish: BFS — eng qisqa yo'l, daraja bo'yicha qidiruv; DFS — barcha yo'llarni chuqur tekshirish, topologik tartiblash kabi masalalarda.

BFS'ning qo'llanilishi

  • Ijtimoiy tarmoqlarda eng qisqa bog'lanish zanjirini topish (masalan, "do'stlar darajasi").
  • GPS va xarita tizimlarida og'irliksiz grafda eng qisqa yo'lni topish.
  • Tarmoq paketlarini translyatsiya qilish (broadcast) algoritmlarida.
  • Web qidiruv tizimlarida sahifalarni indekslashda (web crawling).

Natija

BFS — navbat asosida ishlaydigan, og'irliksiz graflarda eng qisqa yo'lni topishga kafolat beruvchi kuchli qidiruv algoritmi. DFS bilan birgalikda u grafларни qidirishning ikki asosiy ustunini tashkil qiladi va ko'plab real hayotiy masalalar — xaritalardan tortib ijtimoiy tarmoqlargacha — aynan shu algoritm asosida yechiladi.

Code Example

function bfs(graph, start) {
    const queue = [start];
    const visited = { [start]: true };
    const result = [];

    while (queue.length) {
        const vertex = queue.shift();
        result.push(vertex);

        for (const neighbor of graph[vertex]) {
            if (!visited[neighbor]) {
                visited[neighbor] = true;
                queue.push(neighbor);
            }
        }
    }
    return result;
}

const graph = { A: ["B", "C"], B: ["A", "D"], C: ["A"], D: ["B"] };
console.log(bfs(graph, "A")); // ["A", "B", "C", "D"]
