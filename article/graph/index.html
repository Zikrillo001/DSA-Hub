Graph Data Structures

Graf (Graph) — ma'lumot elementlari o'rtasidagi munosabatlarni ifodalaydigan ma'lumotlar tuzilmasi. Graf tartibli juftlik sifatida aniqlanadi: G = (V, E), bu yerda V — tugunlar (cho'qqilar) to'plami, E — qirralar to'plami bo'lib, har bir qirra ikki tugun o'rtasidagi munosabatni ko'rsatadi. Boshqa misollar: ijtimoiy tarmoqlar, yo'l xaritalari, elektr va aloqa tarmoqlari, aviayo'nalishlar.

Illustration

Grafning asosiy tushunchalari

  • Tugun / Cho'qqi (Vertex): Grafdagi har bir alohida element. Barcha tugunlar to'plami V bilan belgilanadi.
  • Qirra (Edge): Ikki tugun orasidagi bog'lanish. Agar u va v tugunlari bog'langan bo'lsa, qirra (u, v) sifatida belgilanadi. Barcha qirralar to'plami E bilan belgilanadi.
  • Qo'shni (Adjacent): Agar (u, v) ∈ E bo'lsa, u va v tugunlari qo'shni deb ataladi.
  • Yo'l (Path): Qirralar orqali bog'langan tugunlar ketma-ketligi. Agar har bir tugun faqat bir marta uchrasa, bu oddiy yo'l (simple path) deyiladi.
  • Sikl (Cycle): Bir xil tugunda boshlanib, shu tugunda yakunlanadigan yo'l.

Yo'naltirilgan va yo'naltirilmagan graflar

Agar grafning har bir qirrasi ma'lum yo'nalishga ega bo'lsa, u yo'naltirilgan graf (directed graph) deb ataladi; aks holda — yo'naltirilmagan graf (undirected graph). Bir tugun juftligi orasida bir nechta qirralarga yoki o'ziga qaytuvchi qirralarga (loop) ruxsat beruvchi graf multigraf (multigraph) deyiladi.

Bog'langan graf va subgraf

  • Bog'langan graf (Connected graph): Har bir juft farqli tugunlar orasida yo'l mavjud bo'lsa, graf bog'langan deyiladi; aks holda — bog'lanmagan.
  • Bog'langan komponent (Connected component): Bog'lanmagan grafning o'z ichida bog'langan qismlari.
  • Subgraf (Subgraph): Asl grafning tugunlari va qirralaridan tanlab olingan qismidan iborat kichik graf.

Grafni ifodalash usullari (Representation)

Grafni dasturda saqlashning ikki asosiy usuli mavjud: Adjacency Matrix (qo'shnilik matritsasi) va Adjacency List (qo'shnilik ro'yxati).

  • Adjacency Matrix: V×V o'lchamli matritsa, unda matrix[i][j] = 1 bo'lsa, i va j tugunlari orasida qirra bor. Qirra mavjudligini tekshirish O(1), lekin xotira O(V²) talab qiladi.
  • Adjacency List: Har bir tugun uchun uning barcha qo'shnilari ro'yxat (list) sifatida saqlanadi. Xotirani samaraliroq ishlatadi — O(V + E).

Grafni JavaScriptda amalga oshirish (Adjacency List)

class Graph {
    constructor() {
        this.adjacencyList = {};
    }

    addVertex(vertex) {
        if (!this.adjacencyList[vertex]) {
            this.adjacencyList[vertex] = [];
        }
    }

    addEdge(v1, v2) {
        this.adjacencyList[v1].push(v2);
        this.adjacencyList[v2].push(v1); // yo'naltirilmagan graf uchun
    }
}

const graph = new Graph();
["A", "B", "C"].forEach(v => graph.addVertex(v));
graph.addEdge("A", "B");
graph.addEdge("A", "C");
// graph.adjacencyList => { A: ["B", "C"], B: ["A"], C: ["A"] }

Grafning muhim algoritmlari

  • Grafni qidirish (Graph Traversal): DFS va BFS — barcha tugunlarni tartib bilan ko'rib chiqish.
  • Topologik tartiblash (Topological Sort): Yo'naltirilgan atsiklik grafdagi tugunlarni bog'liqliklariga mos tartibda joylashtirish.
  • Yoyilgan daraxt (Spanning Tree): Bog'langan grafning barcha tugunlarini siklsiz bog'laydigan daraxt.
  • Minimal yoyilgan daraxt (Minimum Spanning Tree): Umumiy qirra og'irligi eng kichik bo'lgan spanning tree (Prim, Kruskal algoritmlari).
  • Eng qisqa yo'l (Shortest Path): Ikki tugun orasidagi eng kam og'irlikdagi yo'lni topish (Dijkstra algoritmi).

Grafning qo'llanilishi

  • Ijtimoiy tarmoqlar — foydalanuvchilar va ularning bog'lanishlari.
  • Xaritalar va GPS navigatsiya tizimlari — eng qisqa yo'lni topish.
  • Kompyuter tarmoqlari va marshrutlash (routing) protokollari.
  • Loyihalarni rejalashtirish — vazifalar orasidagi bog'liqlik (topologik tartiblash).

Natija

Graf — tugunlar va ular orasidagi munosabatlarni ifodalashning eng moslashuvchan usuli bo'lib, ijtimoiy tarmoqlardan tortib marshrutlashgacha bo'lgan ko'plab real dunyo masalalarini yechishda qo'llaniladi. Grafni to'g'ri ifodalash (matritsa yoki ro'yxat) va unga mos algoritm tanlash — samarali yechimning kalitidir.

Code Example

class Graph {
    constructor() {
        this.adjacencyList = {};
    }
    addVertex(v) {
        if (!this.adjacencyList[v]) this.adjacencyList[v] = [];
    }
    addEdge(v1, v2) {
        this.adjacencyList[v1].push(v2);
        this.adjacencyList[v2].push(v1);
    }
    removeEdge(v1, v2) {
        this.adjacencyList[v1] = this.adjacencyList[v1].filter(v => v !== v2);
        this.adjacencyList[v2] = this.adjacencyList[v2].filter(v => v !== v1);
    }
}

const graph = new Graph();
["A", "B", "C", "D"].forEach(v => graph.addVertex(v));
graph.addEdge("A", "B");
graph.addEdge("A", "C");
graph.addEdge("B", "D");
