Depth-First Search (DFS)

Depth-First Search (DFS) — chuqurlik bo'yicha qidiruv algoritmi bo'lib, ikkita tugun orasidagi yo'lni topish uchun har bir mumkin bo'lgan yo'lni imkon qadar chuqurroq tekshirib, keyin orqaga qaytishni (backtracking) amalga oshiradi. DFS odatda rekursiya yoki stack yordamida amalga oshiriladi va bir tugundan erishish mumkin bo'lgan barcha tugunlarni topishda ishlatiladi.

Illustration

DFS'ning asosiy g'oyasi

  • Rekursiv orqaga qaytish: Hozirgi tugun "ko'rildi" deb belgilanadi, so'ng undan barcha ko'rilmagan qo'shnilar tekshiriladi — har safar imkon qadar chuqurroq davom etiladi.
  • Backtracking: Agar hozirgi tugundan davom etish imkoni qolmasa (barcha qo'shnilar ko'rilgan bo'lsa), algoritm bir qadam orqaga qaytadi va boshqa yo'lni sinab ko'radi.
  • Misollar: "San-Fransiskodan boshlab qayerlarga bora olaman?" yoki "mening do'stlarim (va ularning do'stlari) postimni oxir-oqibat nechta odam ko'radi?" kabi masalalar DFS bilan yechiladi.

DFS qadam-baqadam qanday ishlaydi?

Quyidagi grafda "a" tugunidan "h" tugunigacha DFS (alifbo tartibida) qanday yurishini ko'ramiz — natijada a → b → e → f → c → i → d → g → h tartibida tashrif buyuriladi va {a, d, g, h} yo'li topiladi:

Graf:     a - b - c
          |   |   |
          d   e   i
          |
          g - h

DFS(a): a ni "ko'rildi" deb belgila
        -> b ni tekshir (ko'rilmagan): DFS(b)
           -> e ni tekshir: DFS(e)
              -> f ni tekshir: DFS(f) ... orqaga qaytish
           -> c ni tekshir: DFS(c)
              -> i ni tekshir: DFS(i) ... orqaga qaytish
        -> d ni tekshir: DFS(d)
           -> g ni tekshir: DFS(g)
              -> h ni tekshir: DFS(h)  -> maqsadga yetdik!

DFS'ning psevdokodi

// Barcha erishish mumkin bo'lgan tugunlarni topish
dfs(v1):
    v1 ni "ko'rildi" deb belgila
    v1 ning har bir ko'rilmagan qo'shnisi n uchun:
        dfs(n)

// Ikki tugun orasidagi yo'lni topish (choose-explore-unchoose)
dfs(v1, v2):
    v1 ni "ko'rildi" deb belgila, yo'lga qo'sh
    v1 ning har bir ko'rilmagan qo'shnisi n uchun:
        agar dfs(n, v2) muvaffaqiyatli bo'lsa:
            yo'l topildi!
    agar barcha qo'shnilar muvaffaqiyatsiz bo'lsa:
        v1 ni yo'ldan olib tashla (orqaga qaytish)

DFS'ni JavaScriptda amalga oshirish

class Graph {
    constructor() {
        this.adjacencyList = {};
    }
    addVertex(v) {
        if (!this.adjacencyList[v]) this.adjacencyList[v] = [];
    }
    addEdge(v1, v2) {
        this.adjacencyList[v1].push(v2);
        this.adjacencyList[v2].push(v1);
    }

    dfs(start, visited = {}, result = []) {
        visited[start] = true;
        result.push(start);

        for (const neighbor of this.adjacencyList[start]) {
            if (!visited[neighbor]) {
                this.dfs(neighbor, visited, result);
            }
        }
        return result;
    }
}

N tugunli, M qirrali grafda DFS O(V + E) vaqt talab qiladi — har bir qirra bir marta, har bir tugun esa eng ko'pi bilan bir marta ko'riladi. Rekursiya stack'i uchun O(V) qo'shimcha xotira kerak bo'ladi.

DFS'ning xususiyatlari

  • Kashfiyot (Discovery): Agar ikki tugun orasida yo'l mavjud bo'lsa, DFS uni topishga kafolat beradi.
  • Qayta tiklash (Reconstruction): Topilgan yo'lni "choose – explore – unchoose" usuli bilan aniq qaytarish oson.
  • Optimallik: DFS optimal emas — yo'lni topishga kafolat beradi, lekin u har doim eng qisqa yoki eng yaxshi yo'l bo'lmasligi mumkin. Masalan, dfs(a, i) uzunroq {a, b, e, f, c, i} yo'lini qaytarishi mumkin, aslida qisqaroq {a, d, h, i} yo'li mavjud bo'lsa ham.

DFS va BFS taqqoslash

  • DFS stack (yoki rekursiya) orqali, BFS esa navbat (queue) orqali amalga oshiriladi.
  • DFS kamroq xotira ishlatadi, lekin eng qisqa yo'lni topishga kafolat bermaydi; BFS ko'proq xotira talab qiladi, ammo og'irliksiz grafda doim eng qisqa yo'lni topadi.
  • DFS — labirint yechish, topologik tartiblash kabi "chuqur" masalalarga; BFS — eng qisqa yo'l, daraja bo'yicha qidiruvga mos.

DFS'ning qo'llanilishi

  • Labirint va bulmak kabi masalalarda yechim yo'lini topish.
  • Topologik tartiblash — vazifalar bog'liqligini aniqlashda.
  • Bog'langan komponentlarni va sikllarni aniqlashda.
  • Fayl tizimlarida papkalarni rekursiv aylanib chiqishda.

Natija

DFS — chuqurlik bo'yicha, backtracking asosida ishlaydigan qidiruv algoritmi bo'lib, yo'l mavjudligini topishga kafolat beradi, biroq eng qisqa yo'lni emas. BFS bilan birgalikda u graf nazariyasi va amaliy dasturlashning asosiy qidiruv vositalaridan birini tashkil etadi.

Code Example

function dfs(graph, start, visited = {}, result = []) {
    visited[start] = true;
    result.push(start);

    for (const neighbor of graph[start]) {
        if (!visited[neighbor]) {
            dfs(graph, neighbor, visited, result);
        }
    }
    return result;
}

const graph = { A: ["B", "C"], B: ["A", "D"], C: ["A"], D: ["B"] };
console.log(dfs(graph, "A")); // ["A", "B", "D", "C"]
