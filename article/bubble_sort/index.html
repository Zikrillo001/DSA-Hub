Bubble Sort

Bubble Sort — eng oddiy tartiblash algoritmlaridan biri bo'lib, massivdagi qo'shni elementlarni ketma-ket solishtirib, agar ular noto'g'ri tartibda bo'lsa, joylarini almashtirish orqali ishlaydi. Nomi "bubble" (pufak) so'zidan olingan — chunki eng katta (yoki eng kichik) element har bir o'tishda suvdagi pufak kabi massivning bir chetiga "ko'tarilib" chiqadi.

Illustration

Bubble Sort'ning asosiy tushunchalari

  • Taqqoslash (Comparison): Har bir qadamda ikki qo'shni element qiymati solishtiriladi.
  • Almashtirish (Swap): Agar chapdagi element o'ngdagisidan katta bo'lsa, ularning joyi almashtiriladi.
  • O'tish (Pass): Massiv bo'ylab bir marta to'liq yurib chiqish. Har bir o'tishdan so'ng eng katta element o'z joyiga — massivning oxiriga — joylashadi.
  • swapped flag: Agar biror o'tishda hech qanday almashtirish bo'lmasa, massiv allaqachon tartiblangan va algoritm erta to'xtatiladi.

Bubble Sort qanday ishlaydi?

Algoritm massivni bir necha marta aylanib chiqadi. Har bir o'tishda qo'shni ikki element solishtiriladi: agar ular to'g'ri tartibda bo'lmasa, joylari almashtiriladi. Bu jarayon massiv to'liq tartiblangunga qadar — ya'ni hech qanday almashtirish kerak bo'lmay qolguncha — davom etadi.

Massiv: [5, 1, 4, 2, 8]

1-o'tish: [1, 4, 2, 5, 8]  -> (5,1) va (4,2) almashtirildi, 8 eng oxiriga chiqdi
2-o'tish: [1, 2, 4, 5, 8]  -> (4,2) almashtirildi
3-o'tish: [1, 2, 4, 5, 8]  -> almashtirish bo'lmadi, massiv tartiblangan!

Bubble Sort'ni JavaScriptda amalga oshirish

Tashqi sikl massiv bo'ylab o'tishlar sonini, ichki sikl esa har bir o'tishda qo'shni elementlarni solishtirishni boshqaradi. swapped flag esa massiv erta tartiblanib qolgan holatlarda algoritmni to'xtatib, vaqtni tejashga yordam beradi:

function bubbleSort(arr) {
    const n = arr.length;
    for (let i = 0; i < n - 1; i++) {
        let swapped = false;
        for (let j = 0; j < n - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                [arr[j], arr[j + 1]] = [arr[j + 1], arr[j]];
                swapped = true;
            }
        }
        // Agar o'tishda almashtirish bo'lmasa, massiv tartiblangan
        if (!swapped) break;
    }
    return arr;
}

bubbleSort([5, 1, 4, 2, 8]); // [1, 2, 4, 5, 8]

Eng yaxshi holat — massiv allaqachon tartiblangan bo'lsa, swapped flag tufayli algoritm bitta o'tishdan so'ng to'xtaydi (O(n)). Eng yomon va o'rtacha holatda esa har bir element uchun qolgan barcha elementlar bilan solishtirish kerak bo'ladi (O(n²)).

Xotira murakkabligi:

Bubble Sort qo'shimcha massiv talab qilmaydi, faqat bir nechta vaqtinchalik o'zgaruvchi ishlatiladi — shuning uchun xotira murakkabligi O(1) ga teng.

Bubble Sort'ning afzalliklari

  • Tushunish va amalga oshirish juda oson — o'rganish uchun eng yaxshi birinchi tartiblash algoritmi.
  • Qo'shimcha xotira talab qilmaydi (O(1) xotira murakkabligi).
  • swapped flag bilan allaqachon tartiblangan yoki qisman tartiblangan massivlarda tezkor ishlaydi.

Bubble Sort'ning kamchiliklari

  • Katta massivlar uchun juda sekin — O(n²) murakkablik amaliy loyihalarda mos kelmaydi.
  • Quick Sort, Merge Sort kabi algoritmlarga nisbatan ancha kam samarali.

Bubble Sort'ning qo'llanilishi

  • Kichik hajmdagi yoki deyarli tartiblangan ma'lumotlarni tezda tartiblashda.
  • Tartiblash algoritmlarining asosiy g'oyasini o'rgatishda — dasturlashni o'rganishdagi birinchi algoritmlardan biri sifatida.

Natija

Bubble Sort — soddaligi tufayli algoritmlarni o'rganishni boshlash uchun ajoyib nuqta, biroq samaradorligi past bo'lgani sababli amaliy loyihalarda kamdan-kam qo'llaniladi. Uni chuqur tushunish, keyinchalik Selection Sort, Insertion Sort va Quick Sort kabi murakkabroq algoritmlarni osonroq o'zlashtirishga yordam beradi.
