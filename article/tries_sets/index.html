Tries and Sets

Trie (prefix tree) — satrlarni ularning umumiy prefikslari (boshlang'ich qismlari) bo'yicha samarali saqlash va qidirish uchun mo'ljallangan daraxt shaklidagi ma'lumotlar tuzilmasi. Set esa faqat noyob (unique) qiymatlarni saqlaydigan, tartibsiz to'plam ma'lumotlar tuzilmasi. Ikkisi ham — matn qidirish va ma'lumotlarni takrorlanmas holda saqlashning asosiy vositalaridan.

Illustration

Trie qanday ishlaydi?

Trie'da har bir tugun bitta harfni ifodalaydi, ildizdan boshlab bitta yo'l — bitta so'z prefiksini bildiradi. Bir nechta so'z bir xil boshlang'ich harflarga ega bo'lsa, ular daraxtda bir xil yo'lni baham ko'radi. Masalan, "apple" va "app" so'zlari "a-p-p" yo'lini baham ko'radi, "apple" esa davom etib "l-e" bilan tugaydi. Har bir so'z tugagan tugun isEndOfWord belgisi bilan ajratiladi.

So'zlar: "apple", "app", "bat", "ball"

root
 ├─ a ─ p ─ p (so'z: "app") ─ l ─ e (so'z: "apple")
 └─ b ─ a ┬ t (so'z: "bat")
           └ l ─ l (so'z: "ball")

Trie'ni JavaScriptda amalga oshirish

class TrieNode {
    constructor() {
        this.children = {};
        this.isEndOfWord = false;
    }
}

class Trie {
    constructor() {
        this.root = new TrieNode();
    }

    insert(word) {
        let node = this.root;
        for (const char of word) {
            if (!node.children[char]) {
                node.children[char] = new TrieNode();
            }
            node = node.children[char];
        }
        node.isEndOfWord = true;
    }

    search(word) {
        let node = this.root;
        for (const char of word) {
            if (!node.children[char]) return false;
            node = node.children[char];
        }
        return node.isEndOfWord;
    }

    startsWith(prefix) {
        let node = this.root;
        for (const char of prefix) {
            if (!node.children[char]) return false;
            node = node.children[char];
        }
        return true;
    }
}

const trie = new Trie();
["cat", "car", "cart", "dog", "dot"].forEach(w => trie.insert(w));
trie.search("cart");      // true
trie.search("ca");        // false (so'z sifatida tugamagan)
trie.startsWith("ca");    // true (prefiks mavjud)

Set ma'lumot tuzilmasi

Set — faqat noyob qiymatlarni saqlaydigan, tartibsiz to'plam. Array/List'dan farqli o'laroq, Set'da elementlar indeks orqali emas, bevosita qiymat orqali boshqariladi va avtomatik ravishda takroriy qiymatlarni rad etadi. JavaScript'da Set hash jadval asosida qurilgan, shuning uchun qo'shish, qidirish va o'chirish amallari o'rtacha holatda O(1) vaqtda bajariladi.

Array/List bilan taqqoslash

  • Noyoblik: Set takroriy qiymatlarni saqlamaydi, Array esa saqlaydi.
  • Tartib: Array elementlari indeks bo'yicha tartiblangan, Set'da bu kafolatlanmaydi.
  • Qidiruv tezligi: Set'da has() amali O(1), Array'da includes() esa O(n).

Set amallarini JavaScriptda amalga oshirish

const setA = new Set([1, 2, 3, 4, 5]);
const setB = new Set([4, 5, 6, 7, 8]);

// Birlashma (Union): A ∪ B
function union(a, b) {
    return new Set([...a, ...b]);
}

// Kesishma (Intersection): A ∩ B
function intersection(a, b) {
    return new Set([...a].filter(x => b.has(x)));
}

// Ayirma (Difference): A - B
function difference(a, b) {
    return new Set([...a].filter(x => !b.has(x)));
}

union(setA, setB);        // {1, 2, 3, 4, 5, 6, 7, 8}
intersection(setA, setB); // {4, 5}
difference(setA, setB);   // {1, 2, 3}

Qo'llanilishi

  • Trie: Avtomatik to'ldirish (autocomplete), imlo tekshiruvchilar (spell checker), IP manzillarni marshrutlash.
  • Set: Ma'lumotlardan takrorlanishlarni olib tashlash (deduplication), a'zolikni tezkor tekshirish, matematik to'plam amallari.

Natija

Trie — satrlarni prefiks bo'yicha samarali saqlash va qidirish uchun, Set esa noyob qiymatlarni tezkor saqlash va tekshirish uchun yaratilgan ixtisoslashgan tuzilmalar. Har ikkisi ham to'g'ri vaziyatda qo'llanilganda, oddiy Array yoki List'ga nisbatan sezilarli samaradorlik beradi.

Code Example

class TrieNode {
    constructor() {
        this.children = {};
        this.isEndOfWord = false;
    }
}

class Trie {
    constructor() {
        this.root = new TrieNode();
    }
    insert(word) {
        let node = this.root;
        for (const char of word) {
            node = node.children[char] ??= new TrieNode();
        }
        node.isEndOfWord = true;
    }
    search(word) {
        let node = this.root;
        for (const char of word) {
            if (!node.children[char]) return false;
            node = node.children[char];
        }
        return node.isEndOfWord;
    }
}

const trie = new Trie();
trie.insert("apple");
console.log(trie.search("apple")); // true
console.log(trie.search("app"));   // false
