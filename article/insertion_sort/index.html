Insertion Sort

Insertion Sort — oddiy va intuitiv tartiblash algoritmi bo'lib, massiv elementlari birma-bir olinib, oldingi (allaqachon tartiblangan) qism ichida o'ziga mos joyga joylashtiriladi. Bu algoritm kichik massivlar yoki allaqachon qisman tartiblangan ma'lumotlar uchun ayniqsa samarali hisoblanadi — xuddi o'yin kartalarini qo'lda tartiblashga o'xshaydi.

Illustration

Insertion Sort'ning asosiy tushunchalari

  • Key (Tanlangan element): Har bir qadamda navbat bilan olinadigan va to'g'ri joyga joylashtiriladigan element.
  • Tartiblangan qism: Massivning chap tomonidagi, allaqachon tartiblangan bo'lak.
  • Siljitish (Shift): Key'dan katta bo'lgan elementlar key uchun joy bo'shatib, bir pozitsiyaga o'ngga suriladi.

Insertion Sort qanday ishlaydi?

Algoritm qadamlari quyidagicha:

  • Massivning ikkinchi elementidan boshlab, har bir elementni oldingi elementlar bilan solishtirish boshlanadi.
  • Agar tanlangan element (key) undan oldingi elementdan kichik bo'lsa, oldingi element o'ngga suriladi.
  • key elementi o'ziga mos pozitsiyaga joylashtirilguncha bu jarayon chapga davom etadi.
  • Massivning barcha elementlari tartiblanmaguncha jarayon takrorlanadi.
Massiv: [5, 2, 4, 6, 1, 3]

1-qadam: key=2 -> [2, 5, 4, 6, 1, 3]
2-qadam: key=4 -> [2, 4, 5, 6, 1, 3]
3-qadam: key=6 -> [2, 4, 5, 6, 1, 3]  (o'z joyida qoladi)
4-qadam: key=1 -> [1, 2, 4, 5, 6, 3]
5-qadam: key=3 -> [1, 2, 3, 4, 5, 6]  (tartiblangan!)

Insertion Sort'ni JavaScriptda amalga oshirish

Asosiy sikl i = 1dan boshlanadi, chunki birinchi element (i = 0) allaqachon o'z joyida deb hisoblanadi. Ichki while sikli esa keydan katta elementlarni o'ngga suradi, so'ng key bo'shagan joyga qo'yiladi:

function insertionSort(arr) {
    for (let i = 1; i < arr.length; i++) {
        let key = arr[i];
        let j = i - 1;

        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }
        arr[j + 1] = key;
    }
    return arr;
}

insertionSort([5, 2, 4, 6, 1, 3]); // [1, 2, 3, 4, 5, 6]

Eng yaxshi holat — massiv allaqachon tartiblangan bo'lsa, har bir element uchun ichki while sikli darhol to'xtaydi (O(n)). Eng yomon holat — massiv butunlay teskari tartiblangan bo'lsa, har bir element oldingi barcha elementlar bilan solishtiriladi (O(n²)).

Xotira murakkabligi:

Insertion Sort qo'shimcha massiv talab qilmaydi — faqat key va j kabi bir nechta o'zgaruvchi ishlatiladi, shuning uchun xotira murakkabligi O(1) ga teng.

Insertion Sort'ning afzalliklari

  • Kichik massivlarda samarali ishlaydi.
  • Allaqachon qisman tartiblangan massivlarda juda tez ishlaydi va vaqtni tejaydi.
  • Xotira jihatidan samarali — qo'shimcha xotira talab qilmaydi (O(1)).
  • Online algoritm — ma'lumotlar oqim (stream) sifatida kelganda ham ishlatish mumkin, chunki har bir yangi elementni darhol to'g'ri joyga qo'yish mumkin.

Insertion Sort'ning kamchiliklari

  • Katta massivlar uchun vaqti sekin (O(n²) murakkabligi tufayli).
  • Massiv teskari tartiblangan bo'lsa, juda sekin ishlaydi.

Insertion Sort'ning qo'llanilishi

  • Kichik hajmdagi yoki deyarli tartiblangan ma'lumotlarni tezda tartiblashda.
  • Boshqa murakkab algoritmlar (masalan, Quick Sort, Tim Sort) ichida kichik bo'lim (sub-array)larni tartiblashda yordamchi algoritm sifatida.
  • Real vaqtda kelayotgan ma'lumotlarni tartiblashda (online sorting).

Natija

Insertion Sort — oddiy bosqichlar orqali ishlaydigan, kichik va qisman tartiblangan massivlarda samarali tartiblash algoritmi. Uning soddaligi va xotira jihatidan tejamkorligi, katta massivlarda sekinligiga qaramay, uni ba'zi amaliy holatlarda — jumladan boshqa algoritmlar ichida yordamchi sifatida — foydali qiladi.
