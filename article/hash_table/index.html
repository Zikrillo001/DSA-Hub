Hash Table

Hash Table (hash jadval) — kalit-qiymat (key-value) juftliklarini saqlash uchun ishlatiladigan ma'lumotlar tuzilmasi bo'lib, hash funksiya yordamida har bir kalitni massiv indeksiga aylantiradi. Shu sababli qo'shish, qidirish va o'chirish amallari o'rtacha holatda O(1) vaqt sarflaydi — bu uni katta hajmdagi ma'lumotlar bilan tezkor ishlash uchun eng mashhur tuzilmalardan biriga aylantiradi.

Illustration

Hash Table'ning asosiy tushunchalari

  • Kalit (Key): Qiymatni topish uchun ishlatiladigan noyob identifikator (masalan, ism, ID raqami).
  • Qiymat (Value): Kalitga bog'langan, haqiqatda saqlanayotgan ma'lumot.
  • Hash funksiya: Kalitni qabul qilib, massivning bo'sh indeksiga mos keladigan sonni qaytaruvchi funksiya.
  • Bucket (indeks katakchasi): Hash funksiya natijasida aniqlangan, qiymat joylashtiriladigan massiv katakchasi.
  • Load Factor: Jadvaldagi elementlar sonining jadval hajmiga nisbati (n / jadval o'lchami). Bu ko'rsatkich qachon jadval kattalashtirilishi (resize) kerakligini belgilaydi.

Hash Table qanday ishlaydi?

Hash table ichida har bir kalit-qiymat juftligi uch bosqichda joylashtiriladi: avval kalit hash funksiyadan o'tkaziladi, so'ng olingan son jadval hajmiga mos indeksga aylantiriladi (odatda modul (%) amali orqali), va nihoyat qiymat shu indeksga yoziladi. Qidiruv vaqtida ham xuddi shu kalit qayta hash qilinadi va bevosita kerakli indeksga murojaat qilinadi — shuning uchun butun massivni aylanib chiqish shart emas.

Hashing va hash funksiya

Hashing — bu ixtiyoriy uzunlikdagi ma'lumotni qisqa va o'zgarmas uzunlikdagi songa (hash kod) aylantirish jarayoni. Yaxshi hash funksiya quyidagi xususiyatlarga ega bo'lishi kerak:

  • Bir xil kalit uchun doim bir xil hash qiymatini qaytarishi (deterministik bo'lishi).
  • Hisoblash tezkor bo'lishi — O(1) vaqtda bajarilishi.
  • Natijalarni jadval bo'ylab imkon qadar tekis (bir xil zichlikda) tarqatishi, shunda to'qnashuvlar kamayadi.

Hashing nafaqat hash table'larda, balki shifrlash (kriptografiya), ma'lumotlar yaxlitligini tekshirish (checksum) va parollarni xavfsiz saqlashda ham keng qo'llaniladi.

// Oddiy hash funksiya - JS
function simpleHash(key, tableSize) {
    let total = 0;
    for (let char of String(key)) {
        total += char.charCodeAt(0);
    }
    return total % tableSize;
}

simpleHash("Ali", 10);   // masalan, 4
simpleHash("Vali", 10);  // masalan, 4 - to'qnashuv!

To'qnashuv (Collision) nima?

Ikki xil kalit hash funksiyadan o'tgandan so'ng bitta indeksga tushib qolsa, bu holat to'qnashuv (collision) deyiladi. Masalan, hash("Ali") = 4 va hash("Vali") = 4 bo'lsa, ikkala qiymat ham 4-indeksga da'vogar bo'lib qoladi. To'qnashuvlar hash table'larda tabiiy holat bo'lib, ularni hal qilishning aniq usullari mavjud.

To'qnashuvni hal qilish usullari

  • Zanjir usuli (Separate Chaining): Har bir indeks o'zining bog'langan ro'yxatini (linked list) saqlaydi. Bir xil indeksga tushgan barcha qiymatlar shu ro'yxatga ketma-ket qo'shiladi.
  • Ochiq adreslash (Open Addressing): Agar indeks band bo'lsa, algoritm jadval bo'ylab (chiziqli, kvadratik yoki double hashing qoidasi bo'yicha) keyingi bo'sh joyni qidirib topadi va qiymatni o'sha yerga joylashtiradi.

Hash Table'ni JavaScriptda amalga oshirish

Quyida zanjir usuli (separate chaining) bilan ishlaydigan oddiy hash table klassi keltirilgan. Har bir bucket massiv sifatida saqlanadi, shuning uchun bir nechta kalit bitta indeksga tushsa ham ma'lumot yo'qolmaydi:

class HashTable {
    constructor(size = 53) {
        this.keyMap = new Array(size);
    }

    _hash(key) {
        let total = 0;
        for (let char of String(key)) {
            total = (total + char.charCodeAt(0)) % this.keyMap.length;
        }
        return total;
    }

    set(key, value) {
        let index = this._hash(key);
        if (!this.keyMap[index]) {
            this.keyMap[index] = [];
        }
        this.keyMap[index].push([key, value]);
    }

    get(key) {
        let index = this._hash(key);
        if (!this.keyMap[index]) return undefined;
        for (let pair of this.keyMap[index]) {
            if (pair[0] === key) return pair[1];
        }
        return undefined;
    }

    remove(key) {
        let index = this._hash(key);
        if (!this.keyMap[index]) return false;
        const pairIndex = this.keyMap[index].findIndex(pair => pair[0] === key);
        if (pairIndex === -1) return false;
        this.keyMap[index].splice(pairIndex, 1);
        return true;
    }
}

const ht = new HashTable();
ht.set("olma", 10);
ht.set("banan", 25);
ht.get("olma");      // 10
ht.remove("banan");  // true

Xotira murakkabligi:

Hash table saqlagan har bir kalit-qiymat juftligi uchun qo'shimcha xotira ajratadi, shuning uchun xotira murakkabligi O(n) ga teng.

Hash Table'ning afzalliklari

  • Qo'shish, qidirish va o'chirish amallari o'rtacha holatda O(1) vaqtda bajariladi.
  • Kalit orqali to'g'ridan-to'g'ri murojaat qilish imkonini beradi — massivni boshidan oxirigacha aylanib chiqish shart emas.
  • Katta hajmdagi ma'lumotlar bilan samarali ishlaydi, shuning uchun indekslash va keshlashda keng qo'llaniladi.

Hash Table'ning kamchiliklari

  • To'qnashuvlar ko'payib ketsa, samaradorlik pasayib, eng yomon holatda O(n) ga tushib qolishi mumkin.
  • Massivdagi kabi tartiblangan holda saqlash yoki tartib bo'yicha yurish (iteration order) kafolatlanmaydi.
  • Yaxshi hash funksiya tanlash va load factor'ni boshqarish (resize) qo'shimcha murakkablik talab qiladi.

Hash Table'ning qo'llanilishi

  • Ma'lumotlar bazalarida va qidiruv tizimlarida tezkor indekslash uchun (masalan, Google qidiruvi).
  • Dasturlash tillaridagi obyekt, dictionary, map kabi tuzilmalarning asosida.
  • Keshlash (caching) tizimlarida tezkor ma'lumot olish uchun.
  • Parollarni xavfsiz saqlash va ma'lumotlar yaxlitligini tekshirishda (checksum, kriptografik hashlar).

Natija

Hash table — kalit orqali ma'lumotga deyarli bir zumda murojaat qilish imkonini beruvchi, zamonaviy dasturlashning asosiy tuzilmalaridan biri. Uning samaradorligi to'g'ridan-to'g'ri hash funksiya sifatiga va to'qnashuvlarni qanday boshqarishga bog'liq. Shu sababli hash table interview'larda eng ko'p so'raladigan mavzulardan biri hisoblanadi va uni chuqur tushunish har bir dasturchi uchun muhim.

Code Example

// Hash Table yaratish
const ht = new HashTable();

// Kalit-qiymat qo'shish

ht.set("banan", 25);
ht.set("gilos", 7);

// Elementni o'chirish
ht.remove("gilos"); // true

// Mavjud bo'lmagan kalit
ht.get("sana");    // undefined
