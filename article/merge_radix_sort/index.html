Merge Sort and Radix Sort

Merge Sort va Radix Sort — ikki xil yondashuvga asoslangan samarali tartiblash algoritmlari. Merge Sort — "bo'lish va hukmronlik qilish" (divide and conquer) strategiyasiga asoslangan taqqoslash algoritmi, Radix Sort esa elementlarni umuman solishtirmay, raqamlarning har bir xonasi bo'yicha tartiblaydigan taqqoslashsiz algoritm.

Illustration

Merge Sort qanday ishlaydi?

Merge Sort massivni uzluksiz ikkiga bo'lib boradi, toki har bir bo'lak bitta elementdan iborat bo'lib qolmaguncha (bitta element — allaqachon "tartiblangan" hisoblanadi). Keyin bu bo'laklar juftlab, tartiblangan holda qaytadan birlashtiriladi (merge):

Massiv: [38, 27, 43, 3, 9]

Bo'lish:
[38, 27, 43, 3, 9] -> [38, 27] va [43, 3, 9]
[38, 27] -> [38] va [27]
[43, 3, 9] -> [43] va [3, 9] -> [3] va [9]

Birlashtirish (merge):
[38] + [27]        -> [27, 38]
[3] + [9]          -> [3, 9]
[3, 9] + [43]      -> [3, 9, 43]
[27, 38] + [3,9,43]-> [3, 9, 27, 38, 43]  (tartiblangan!)

Merge Sort'ni JavaScriptda amalga oshirish

function mergeSort(arr) {
    if (arr.length <= 1) return arr;

    const mid = Math.floor(arr.length / 2);
    const left = mergeSort(arr.slice(0, mid));
    const right = mergeSort(arr.slice(mid));

    return merge(left, right);
}

function merge(left, right) {
    const result = [];
    let i = 0, j = 0;

    while (i < left.length && j < right.length) {
        if (left[i] <= right[j]) result.push(left[i++]);
        else result.push(right[j++]);
    }
    return result.concat(left.slice(i)).concat(right.slice(j));
}

mergeSort([38, 27, 43, 3, 9]); // [3, 9, 27, 38, 43]

Radix Sort qanday ishlaydi?

Radix Sort elementlarni bir-biri bilan solishtirmaydi — buning o'rniga sonlarning raqamlarini (xonalarini) eng kichik xonadan (birlik) boshlab, eng katta xonagacha, har bir xona bo'yicha alohida tartiblaydi. Har bir xonani tartiblash uchun odatda barqaror (stable) Counting Sort ishlatiladi:

Massiv: [170, 45, 75, 90, 802, 24, 2, 66]

1-xona (birlik) bo'yicha: [170, 90, 802, 2, 24, 45, 75, 66]
2-xona (o'nlik) bo'yicha: [802, 2, 24, 45, 66, 170, 75, 90]
3-xona (yuzlik) bo'yicha: [2, 24, 45, 66, 75, 90, 170, 802]  (tartiblangan!)

Radix Sort'ni JavaScriptda amalga oshirish

function radixSort(arr) {
    const max = Math.max(...arr);
    const maxDigits = String(max).length;

    for (let k = 0; k < maxDigits; k++) {
        const buckets = Array.from({ length: 10 }, () => []);

        for (const num of arr) {
            const digit = Math.floor(num / 10 ** k) % 10;
            buckets[digit].push(num);
        }
        arr = [].concat(...buckets);
    }
    return arr;
}

radixSort([170, 45, 75, 90, 802, 24, 2, 66]);
// [2, 24, 45, 66, 75, 90, 170, 802]

Bu yerda d — sondagi xonalar (raqamlar) soni, b — sanoq asosi (odatda 10). Merge Sort har doim barqaror O(n log n) natija beradi — massiv holatidan qat'i nazar. Radix Sort esa xonalar soni kichik bo'lgan butun sonlar uchun bundan ham tezroq (deyarli chiziqli) ishlaydi, lekin faqat ma'lum formatdagi ma'lumotlar (butun sonlar, fiksirlangan uzunlikdagi satrlar) uchun mos keladi.

Ma'lumot turlariga mosligi

  • Merge Sort: Umumiy algoritm — har qanday solishtiriladigan ma'lumot turi (son, satr, obyekt) uchun ishlaydi. Shuningdek barqaror (stable) algoritm — teng elementlarning nisbiy tartibini saqlaydi.
  • Radix Sort: Faqat butun sonlar yoki fiksirlangan uzunlikdagi satrlar kabi "raqamli xonalarga" ega ma'lumotlar uchun mos. Manfiy sonlar va o'nlik kasrlar uchun qo'shimcha moslashtirish talab qiladi.

Afzalliklari va kamchiliklari

  • Merge Sort — barqaror va kafolatlangan O(n log n), lekin qo'shimcha O(n) xotira talab qiladi (in-place emas).
  • Radix Sort — to'g'ri ma'lumot turi uchun O(n log n)dan tezroq bo'lishi mumkin, lekin faqat cheklangan ma'lumot turlariga mos va qo'shimcha "bucket" xotirasi talab qiladi.

Qo'llanilishi

  • Merge Sort — katta hajmdagi ma'lumotlarni tashqi xotirada (external sorting) tartiblashda, barqarorlik muhim bo'lgan holatlarda (masalan, ko'p mezon bo'yicha saralash).
  • Radix Sort — katta hajmdagi butun sonlarni (masalan, pochta indekslari, telefon raqamlari) tezkor tartiblashda.

Natija

Merge Sort — ishonchli, barqaror va universal "bo'lish va hukmronlik qilish" algoritmi, Radix Sort esa ma'lum shartlar bajarilganda undan ham tezroq natija beruvchi taqqoslashsiz algoritm. Qaysi birini tanlash ma'lumot turiga va vazifa talablariga bog'liq: umumiy holatlarda Merge Sort, raqamli ma'lumotlarni tezkor tartiblashda esa Radix Sort afzalroq.

Code Example

function mergeSort(arr) {
    if (arr.length <= 1) return arr;
    const mid = Math.floor(arr.length / 2);
    const left = mergeSort(arr.slice(0, mid));
    const right = mergeSort(arr.slice(mid));
    const result = [];
    let i = 0, j = 0;
    while (i < left.length && j < right.length) {
        result.push(left[i] <= right[j] ? left[i++] : right[j++]);
    }
    return result.concat(left.slice(i), right.slice(j));
}

console.log(mergeSort([38, 27, 43, 3, 9]));
// [3, 9, 27, 38, 43]
