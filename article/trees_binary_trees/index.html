Trees and Binary Trees

Tree (daraxt) — ma'lumotlar tuzilmasi bo'lib, unda elementlar tugun (node) sifatida tashkil topgan va ular orasida ota-ona (parent) va farzand (child) bog'lanishlari mavjud. Binary Tree esa daraxtning maxsus turi — unda har bir tugunning maksimal ikkita farzandi bo'ladi. Bu tuzilmalar fayl tizimlari, ma'lumotlar bazalari va tezkor qidiruv algoritmlarining asosini tashkil qiladi.

Illustration

Daraxtning asosiy tushunchalari

  • Root (Ildiz): Daraxtning boshlang'ich, eng yuqoridagi tuguni.
  • Node (Tugun): Daraxtdagi har bir alohida element.
  • Leaf (Barg): Farzandi (child) yo'q tugun.
  • Edge (Qirra): Ikki tugun orasidagi bog'lanish.
  • Depth (Chuqurlik): Tugunning ildizdan bo'lgan masofasi.
  • Height (Balandlik): Daraxtning eng chuqur tuguni bilan ildiz o'rtasidagi masofa.
  • Subtree (Pastki daraxt): Har qanday tugun va unga bog'langan barcha farzandlardan iborat qism.

Daraxtlarning ishlatilish o'rni

  • Fayllar va papkalar tuzilmasi (katalog strukturasi).
  • Tashkilot tuzilmasi, ierarxik diagrammalar (organogramma).
  • Ma'lumot qidirish tizimlari — masalan, Binary Search Tree.

Daraxt tuzilmasini JavaScriptda yaratish

Node klassi har bir tugunning ma'lumotini va farzandlarini saqlaydi, Tree klassi esa ildizni belgilash va yangi tugun qo'shish imkonini beradi:

class Node {
    constructor(value) {
        this.value = value;
        this.children = [];
    }
}

class Tree {
    constructor(rootValue) {
        this.root = new Node(rootValue);
    }

    addChild(parent, value) {
        const child = new Node(value);
        parent.children.push(child);
        return child;
    }
}

Binary Tree (ikkilik daraxt) nima?

Binary Tree — har bir tugunning maksimal ikkita farzandi (chap va o'ng) bo'lgan daraxt turi. Binary Tree bir necha asosiy turga bo'linadi:

  • Complete Binary Tree: Hamma darajadagi tugunlar — eng pastki darajadan tashqari — to'liq to'lgan.
  • Full Binary Tree: Har bir tugunning yoki ikkita farzandi bor, yoki umuman farzandi yo'q.
  • Perfect Binary Tree: Hamma darajalar to'liq to'lgan va barcha barglar bir xil chuqurlikda.
  • Balanced Tree: Har bir tugunning chap va o'ng pastki daraxtlari balandligi ko'pi bilan bittaga farq qiladi.
class Node {
    constructor(value) {
        this.value = value;
        this.left = null;
        this.right = null;
    }
}

class BinaryTree {
    constructor(rootValue) {
        this.root = new Node(rootValue);
    }
}

Binary Search Tree (BST)

Binary Search Tree — binary tree turi bo'lib, unda quyidagi qoida amal qiladi: har bir tugunning chap farzandlari undan kichik, o'ng farzandlari esa undan katta qiymatga ega. BST'da qiymatlar noyob bo'ladi. Daraxt muvozanatlangan bo'lsa, qo'shish, qidirish va o'chirish amallari O(log n) vaqtda bajariladi.

class BSTNode {
    constructor(value) {
        this.value = value;
        this.left = null;
        this.right = null;
    }
}

class BinarySearchTree {
    constructor() {
        this.root = null;
    }

    insertNode(node, value) {
        if (!node) return new BSTNode(value);
        if (value < node.value) {
            node.left = this.insertNode(node.left, value);
        } else if (value > node.value) {
            node.right = this.insertNode(node.right, value);
        }
        return node;
    }

    insert(value) {
        this.root = this.insertNode(this.root, value);
    }

    search(node, value) {
        if (!node) return null;
        if (value === node.value) return node;
        return value < node.value
            ? this.search(node.left, value)
            : this.search(node.right, value);
    }
}

const bst = new BinarySearchTree();
[8, 3, 10, 1, 6].forEach(v => bst.insert(v));
bst.search(bst.root, 6); // BSTNode { value: 6, ... }

Daraxtlarda yurish (Tree Traversal) usullari

Daraxtdagi barcha tugunlarni ma'lum tartibda ko'rib chiqish uchun ikki asosiy usul qo'llaniladi: DFS (Depth-First Search) va BFS (Breadth-First Search).

  • DFS: Har bir yo'lni imkon qadar chuqur tekshirib, keyin orqaga qaytadi. Odatda rekursiya yoki stack orqali amalga oshiriladi. Labirint kabi masalalarda qulay.
  • BFS: Daraxtning har bir darajasi bo'yicha, yuqoridan pastga qarab yuradi. Navbat (queue) yordamida amalga oshiriladi. Eng qisqa yo'lni topish kabi masalalarda qulay.

Daraxtlarda ko'p uchraydigan amallar

  • Qo'shish (Insertion): Daraxtga yangi tugun qo'shish.
  • O'chirish (Deletion): Daraxtdan tugunni o'chirish.
  • Qidirish (Search): Ma'lum bir qiymatni daraxtda qidirish.
  • AVL va Red-Black daraxtlari: Balandligi avtomatik boshqariladigan, muvozanatlashgan maxsus BST turlari.

Daraxtlarning amaliy ishlatilish o'rni

  • Qidiruv algoritmlari — ma'lumotlarni tezkor topish uchun (BST).
  • Kompilyatorlar — sintaksis daraxtlarini yaratishda.
  • Tarmoq va yo'l topish — eng qisqa yo'llarni aniqlashda.
  • Sun'iy intellekt — o'yinlarda qaror daraxtlari (masalan, shaxmatda harakatlarni simulyatsiya qilish).

Natija

Tree va Binary Tree — ierarxik ma'lumotlarni tabiiy tarzda ifodalash va tezkor qidiruv imkonini beruvchi asosiy ma'lumotlar tuzilmalari. Binary Search Tree kabi maxsus turlari orqali qidirish, qo'shish va o'chirish amallarini o'rtacha holatda logarifmik vaqtda bajarish mumkin, bu esa ularni ko'plab amaliy tizimlarning poydevoriga aylantiradi.

Code Example

class BSTNode {
    constructor(value) {
        this.value = value;
        this.left = null;
        this.right = null;
    }
}

class BinarySearchTree {
    constructor() {
        this.root = null;
    }
    insert(value) {
        this.root = this._insert(this.root, value);
    }
    _insert(node, value) {
        if (!node) return new BSTNode(value);
        if (value < node.value) node.left = this._insert(node.left, value);
        else if (value > node.value) node.right = this._insert(node.right, value);
        return node;
    }
}

const tree = new BinarySearchTree();
[8, 3, 10, 1, 6, 14].forEach(v => tree.insert(v));
